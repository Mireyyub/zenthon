# Lesson 000007

Title
Effect

Definition
Nəticə səbəbin törətdiyi hadisə və ya dəyişiklikdir.

Examples
od → tüstü (tüstü nəticədir)
yağış → islanma

Rules
Nəticə səbəbdən sonra gəlir.
Eyni səbəb bir neçə nəticə doğura bilər.

Exercises
Tüstü odun nəticəsi ola bilərmi?
Bəli.

Nəticə səbəbdən əvvəl gələ bilərmi?
Xeyr.

Yerin islanması yağışın nəticəsi ola bilərmi?
Bəli.
