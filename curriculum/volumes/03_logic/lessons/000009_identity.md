# Lesson 000009

Title
Identity

Definition
Hər obyekt özünə bərabərdir.
Əgər X mövcuddursa, X = X doğrudur.
İki fərqli ad eyni obyektə işarə edə bilər, lakin fərqli obyektlər eyni deyil.

Examples
alma = alma
Yer = Yer
Leon = Leon

Counter Examples
alma = daş
insan = planet

Logical Rules
Əgər X obyektdirsə, X = X.
Əgər X ≠ Y doğrudursa, X və Y eyni obyekt deyil.

Rules
Heç vaxt fərqli obyektləri eyni hesab etmə.
Oxşarlıq eynilik deyil.

Exercises
