# Lesson 000011

Title
Inference

Definition
Nəticə çıxarma: verilmiş qayda və faktdan yeni iddia törətmək.
Əgər “A → B” (əgər A onda B) və A doğrudursa, B doğrudur.

Examples
Əgər yağış yağırsa, yer islanır. Yağış yağır → yer islanır.
Əgər X meyvədirsə, X bitki mənşəlidir. Alma meyvədir → alma bitki mənşəlidir.

Counter Examples
Yalnız B-dən A-ya qayıtmaq (əks istiqamət) həmişə doğru deyil.

Logical Rules
Modus ponens: A → B, A ⊢ B
Yalnız B-nin doğru olması A-nı sübut etmir.

Rules
Qayda və fakt uyğun gəlməyəndə uydurma.

Exercises
Əgər A → B və A doğrudursa, B haqqında nə deyə bilərik?
B doğrudur.

Yalnız B doğru olsa, A mütləq doğrudurmu?
Xeyr.

Alma meyvədir və meyvələr bitki mənşəlidirsə, alma bitki mənşəlidirmi?
Bəli.
